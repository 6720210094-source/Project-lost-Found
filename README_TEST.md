# รายงานและคู่มือการทดสอบระบบด้วย Playwright (Automated Testing)
**ระบบ Lost & Found (ระบบแจ้งของหายและส่งคืนเจ้าของ)**

---

## 📁 รายการไฟล์ในชุดทดสอบนี้
1. `playwright.config.ts` - ไฟล์การตั้งค่า Playwright และการรัน WebServer อัตโนมัติ
2. `tests/report-lost.spec.ts` - ชุดทดสอบฟังก์ชันที่ 1: หน้าแจ้งของหาย
3. `tests/handover.spec.ts` - ชุดทดสอบฟังก์ชันที่ 2: หน้าส่งมอบ/ส่งคืนเจ้าของ

---

## 🚀 วิธีการติดตั้งและรันชุดทดสอบ (How to Run)

### 1. ติดตั้ง Dependencies (หากยังไม่ได้ติดตั้ง)
```bash
npm install -D @playwright/test
npx playwright install chromium
```

### 2. คำสั่งรันการทดสอบ
* **รันการทดสอบทั้งหมด (Headless Mode):**
  ```bash
  npx playwright test
  ```
* **รันการทดสอบพร้อมเปิดหน้าต่างเบราว์เซอร์ให้เห็นขั้นตอนจริง (Headed Mode):**
  ```bash
  npx playwright test --headed
  ```
* **เปิดดูผลรายงานการทดสอบแบบละเอียด (HTML Report):**
  ```bash
  npx playwright show-report
  ```

## 📋 รายละเอียดขั้นตอนการทดสอบ (Test Steps & Results)

### ฟังก์ชันที่ 1: หน้าแจ้งของหาย (Report Lost Item)
*ไฟล์: `tests/report-lost.spec.ts`*

1. **เคสที่ 1.1: ตรวจสอบการแสดงผลองค์ประกอบหลัก (UI Component Check)**
   * **ขั้นตอน:** เปิดหน้า `/report-lost`
   * **สิ่งที่ตรวจ:** ตรวจสอบว่ามีหัวข้อ "แจ้งของหาย", ช่องกรอกชื่อสิ่งของ, ตัวเลือกหมวดหมู่, สถานที่, รายละเอียด, ช่องอัปโหลดรูปภาพ และปุ่มส่งข้อมูลครบถ้วน
   * **ผลลัพธ์:** ผ่าน (Passed)

2. **เคสที่ 1.2: ตรวจสอบตัวเลือกหมวดหมู่สิ่งของ (Category Dropdown)**
   * **ขั้นตอน:** จำลองการคลิกเลือกประเภทสิ่งของทั้ง 6 หมวดหมู่ (อุปกรณ์อิเล็กทรอนิกส์, กระเป๋า, เอกสาร, เสื้อผ้า, ของใช้ส่วนตัว, อื่น ๆ)
   * **สิ่งที่ตรวจ:** ค่าที่เลือกสัมพันธ์กับ Dropdown อย่างถูกต้อง
   * **ผลลัพธ์:** ผ่าน (Passed)

3. **เคสที่ 1.3: ตรวจสอบการกรอกข้อมูลในฟอร์ม (Form Input Simulation)**
   * **ขั้นตอน:** กรอกชื่อสิ่งของ ("หูฟัง AirPods Pro 2"), ระบุสถานที่ และรายละเอียด
   * **สิ่งที่ตรวจ:** ค่าใน Input และ Textarea ตรงตามที่กรอก
   * **ผลลัพธ์:** ผ่าน (Passed)

4. **เคสที่ 1.4: ตรวจสอบระบบรักษาความปลอดภัยและการแจ้งเตือน (Authentication Guard)**
   * **ขั้นตอน:** จำลองผู้ใช้ทั่วไป (Guest ที่ยังไม่ได้ล็อกอิน) กรอกข้อมูลแล้วกดปุ่มส่งแจ้งของหาย
   * **สิ่งที่ตรวจ:** ระบบต้องปฏิเสธการส่ง และแสดงกล่องข้อความเตือนสีแดง "⚠️ กรุณาเข้าสู่ระบบก่อนทำการแจ้งรายการ"
   * **ผลลัพธ์:** ผ่าน (Passed)

---

### ฟังก์ชันที่ 2: หน้าส่งคืนเจ้าของและการส่งมอบ (Handover & Return)
*ไฟล์: `tests/handover.spec.ts`*

1. **เคสที่ 2.1: ตรวจสอบการแสดงผลหน้าส่งมอบของคืน (/handover)**
   * **ขั้นตอน:** เปิดหน้า `/handover`
   * **สิ่งที่ตรวจ:** ตรวจสอบหัวข้อ "ส่งมอบของคืน", ข้อความแนะนำการใช้งาน และการแสดงรายการสิ่งของที่รอการส่งมอบ
   * **ผลลัพธ์:** ผ่าน (Passed)

2. **เคสที่ 2.2: ตรวจสอบระบบความปลอดภัยหน้าประวัติการส่งมอบ (/handover-history)**
   * **ขั้นตอน:** เปิดหน้า `/handover-history` ขณะยังไม่ได้ล็อกอิน
   * **สิ่งที่ตรวจ:** ตรวจสอบการบล็อกสิทธิ์เพื่อปกป้องข้อมูลส่วนบุคคล โดยระบบต้องแสดงข้อความ "กรุณาเข้าสู่ระบบก่อนดูประวัติ"
   * **ผลลัพธ์:** ผ่าน (Passed)

3. **เคสที่ 2.3: ตรวจสอบการนำทางระหว่างหน้าหลักไปยังประวัติส่งมอบจาก Navbar**
   * **ขั้นตอน:** เข้าหน้าแรก `/` และคลิกเมนู "ประวัติการส่งมอบ" บน Navbar
   * **สิ่งที่ตรวจ:** หน้าเว็บเปลี่ยนเส้นทางไปยัง `/handover-history` ได้ถูกต้อง
   * **ผลลัพธ์:** ผ่าน (Passed)

4. **เคสที่ 2.4: ตรวจสอบตัวกรองสถานะการส่งคืนและรายการสิ่งของ (/lost Status Filtering)**
   * **ขั้นตอน:** ทดสอบเลือกฟิลเตอร์สถานะสิ่งของระหว่าง "กำลังตามหา" กับ "ส่งคืนแล้ว"
   * **สิ่งที่ตรวจ:** สลับสถานะได้ถูกต้องตามเงื่อนไข
   * **ผลลัพธ์:** ผ่าน (Passed)
