   FoundIt – Lost & Found Hub

ระบบเว็บแอปพลิเคชันสำหรับแจ้งและติดตามสิ่งของหายและสิ่งของที่พบภายในมหาวิทยาลัย ช่วยให้ผู้ใช้งานสามารถประกาศรายการสิ่งของ ค้นหาสิ่งของ ติดต่อเจ้าของหรือผู้พบผ่านระบบ Chat และติดตามสถานะของรายการได้อย่างสะดวก

  About the Project

FoundIt – Lost & Found Hub เป็นระบบจัดการสิ่งของหายและสิ่งของที่พบ โดยออกแบบมาเพื่อช่วยแก้ปัญหาการตามหาสิ่งของภายในมหาวิทยาลัย
ผู้ใช้งานสามารถ
* สมัครสมาชิกและเข้าสู่ระบบ
* แจ้งสิ่งของที่สูญหาย
* แจ้งสิ่งของที่พบ
* ค้นหารายการสิ่งของ
* ดูรายละเอียดของสิ่งของ
* ติดต่อผู้แจ้งผ่านระบบ Chat
* จัดการรายการที่ตนเองแจ้ง
* ติดตามสถานะของรายการ

นอกจากนี้ระบบยังมี **Admin** สำหรับจัดการผู้ใช้งาน รายการสิ่งของ และคำร้องต่าง ๆ ภายในระบบ Features
