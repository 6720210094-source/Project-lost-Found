FoundIt – Lost & Found Hub

ระบบเว็บแอปพลิเคชันสำหรับแจ้งและติดตามสิ่งของหายและสิ่งของที่พบภายในมหาวิทยาลัย ช่วยให้ผู้ใช้งานสามารถประกาศรายการสิ่งของ ค้นหาสิ่งของ ติดต่อเจ้าของหรือผู้พบผ่านระบบ Chat และติดตามสถานะของรายการได้อย่างสะดวก

About the Project

FoundIt – Lost & Found Hub เป็นระบบจัดการสิ่งของหายและสิ่งของที่พบภายในมหาวิทยาลัย โดยมีจุดประสงค์เพื่อช่วยให้ผู้ที่ทำสิ่งของหายสามารถค้นหาและติดต่อผู้พบสิ่งของได้ง่ายขึ้น รวมถึงช่วยให้ผู้ที่พบสิ่งของสามารถแจ้งข้อมูลและประสานงานเพื่อส่งคืนเจ้าของได้

เพื่อให้ตรงกับระบบที่เรากำลังทำอยู่ ซึ่งเมื่อกดยืนยันจะมีขั้นตอน:

ชื่อผู้รับ → รหัสนักศึกษา → ลายเซ็น → ยืนยัน → บันทึกวันเวลา → RESOLVED
